# Promotional Strategy Insight (Python)

Overview:
Analyzed in-store promotions (BOGO, discounts, special events) using Python (Pandas, NumPy) to calculate sales lift.
Key finding: Special events increased sales by 38% over baseline.
Recommended sustainability-themed campaigns (e.g., discount-for-recyclables) to align with brand values and boost customer engagement.




## Project Motivation and Impact

- quantifies the true impact of retail promotions 
- dives into 3 types of promotions which are used to identity that special events is the msot imapctful among customers




## Extending the project 

- Time series analysis to capture seasonal effect
- Generative AI integration for automated reporting


## key results
| Promotion Type | Sales Lift (%) |
| -------------- | -------------- |
| BOGO           | +22%           |
| Discount       | +15%           |
| Special Event  | **+38%**       |
